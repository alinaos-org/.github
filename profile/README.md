## ALINA OS: the AI that knows you should belong to you

ALINA OS is an AI-native operating system on NixOS, in daily use today. You speak or type,
and a fleet of agents works across the whole machine, with rules about what they remember,
a visible record of what they do, and review before anything consequential happens.

**Where it's going:** an always-on intelligence personal to one human. A personal model
that knows you holds the plan and calls frontier models when a task needs them. Your
memory, authority and identity live in an OS you own, and every model and agent app is
a part you can swap. **[Read the vision →](https://alinaos.com/vision/)**

<p align="center">
  <img src="https://raw.githubusercontent.com/alinaos-org/alinaos-showcase/main/images/north-star/three-memories.jpg" alt="Three memories: episodic, semantic and parametric" width="100%">
</p>

- **Three memories, one self.** Episodic: Loom, one ledger of every session in every
  agent app (live). Semantic: facts curated nightly by a council of models from three
  labs (live). Parametric: [Engram](https://github.com/alinaos-org/engram), a personal
  model with memory in its weights (research).
- **Earned, never assumed.** The personal model takes over a role only when it beats
  frontier models plus retrieval on a benchmark built from your own sessions.
- **Your data, your rules.** Client and export-controlled work never trains your model.
  Anything outbound waits for your approval.
- **At home.** The target is an ALINA box per person: a NixOS machine running your
  agents, ledger, memory and model under your roof. Long range, custom silicon from
  [ControlStackAI Silicon](https://github.com/controlstackai-silicon).

**What runs today:** partitioned memory that fails closed, a desktop that is an API with
every agent window signed and audited, cross-model review with exact-action approvals
and receipts, and a whole machine declared in a flake.
