## Updating the profile

Edit `profile/README.md` and check its rendered Markdown, image links, and public URLs before publishing. Keep capability statements aligned with the referenced project’s current implementation and maturity. Do not include private infrastructure, configuration, or agent memory.

This repository contains community presentation material, not the operating-system implementation. Follow individual project READMEs for installation and support.
